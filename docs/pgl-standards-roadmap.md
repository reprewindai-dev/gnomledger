# PGL Standards Roadmap

The path to an industry-wide open standard requires momentum, solid reference implementations, and demonstrable interoperability. We adhere to the **Leverage Principle**: do not go to standards bodies with an idea. Go with an open spec, two SDKs, three implementations, conformance tests, and live interoperability.

## Roadmap Steps

1. **Freeze PGL semantics** — ✅ (Completed in v0.1)
2. **Publish PGL 0.1** — ✅
3. **JSON Schemas** — ✅ (Completed for the 5 normative primitives)
4. **Test Vectors** — Define reference vectors for valid delegation, expired delegation, revoked authority, replay attempts, and evidence verification.
5. **Reference SDKs** — Release official TypeScript and Python SDKs for PGL processing.
6. **A2A Extension Profile** — Implement and document the PGL extension standard over A2A.
7. **MCP Profile** — Create an MCP server profile returning PGL evidence references.
8. **Web Bot Auth Binding** — Define bindings for HTTP sender ↔ Origin validation.
9. **x402 Binding** — Define bindings integrating the payer and settlement references into the PGL evidence envelope.
10. **Conformance Suite** — Build and release a testing suite to validate third-party PGL implementations.
11. **Real Interop Demos** — Demonstrate live exchange of PGL evidence between a Veklom agent and a non-Veklom A2A agent.
12. **Standards Bodies / Foundations** — Submit the mature, proven specification to relevant standards bodies.
